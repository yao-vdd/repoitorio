# Regras do projeto

- Site de portfólio pessoal em HTML, CSS e JavaScript puro (sem frameworks).
- Antes de criar ou alterar qualquer coisa, leia `referencias.md`, `identidade.md` e `funcionalidades.md`.
- Mantenha o código organizado: um arquivo CSS (`style.css`), um JS (`script.js`), e o HTML (`index.html`) com seções devidamente nomeadas e semânticas.
- Nada de layout genérico de template: siga rigorosamente as referências e a identidade visual do aluno.
- Sempre responsivo (celular, tablet e computador).
- Depois de cada mudança, explique em 2 linhas o que foi feito.
